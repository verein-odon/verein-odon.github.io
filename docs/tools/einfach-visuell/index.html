Hilfe

Zeig es, statt es zu beschreiben.

So funktioniert's

  1. Ausschnitt aufnehmen Nimm einen Bildschirmausschnitt von dem auf, worüber du sprichst.
  2. Einfügen & markieren Füge ihn ein und ziehe Symbole darauf, um zu zeigen, was du meinst.
  3. Ergebnis aufnehmen Nimm die Fläche auf demselben Weg auf — fertig zum Teilen.

Kurz notiert

  • Ziehen platziert ein Symbol
  • Aufziehen markiert einen Bereich
  • Griff beim Überfahren verschiebt, × entfernt
  • Mausrad zoomt, Ziehen schwenkt
