NOTE ON CLASS NAMES: the banner uses 'prefs-bar' / 'prefs-btn' rather than the obvious 'cookie-banner' / 'cookie-btn'. Cookie-notice filter lists (EasyList Cookie, Fanboy's Annoyances — and Brave, which blocks consent notices by DEFAULT, including in private windows) cosmetically hide elements matching #cookie-banner / .cookie-banner.
